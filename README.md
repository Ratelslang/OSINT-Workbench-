# OSINT Workbench
Offline investigation and profiling graph. Single-file app, no build step, no network calls. Data stays in this browser.

Deploy: upload all files to the repo root, enable GitHub Pages (main / root), open the URL, install from the address bar.
Your old v1 case is migrated automatically on first open. Update: after uploading, reload twice so the new service worker takes over.

Shortcuts: Ctrl+Z/Y undo/redo, L link mode, F fit, Del delete, Ctrl+A select all, Esc clear, Shift+drag box-select, Shift+drag between entities to link, double-click empty space to add.
